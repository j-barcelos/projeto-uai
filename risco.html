⚠️ Plano de Gerenciamento de Riscos

Identificação, análise e mitigação de riscos do projeto

R01 - Atraso na entrega de conteúdo pelo cliente

Cliente não fornece fotos, textos ou aprovações nos prazos estabelecidos.

ALTO
Probabilidade: 60%
Impacto: Crítico
Mitigação: Definir deadlines claros no contrato; manter follow-up semanal; ter conteúdo placeholder preparado

R02 - Mudanças de escopo durante o desenvolvimento

Novas funcionalidades ou alterações solicitadas após início do desenvolvimento.

MÉDIO
Probabilidade: 50%
Impacto: Moderado
Mitigação: Processo formal de change request; reserva de buffer de 15% no cronograma; sinalização de impacto no prazo/orçamento

R03 - Problemas de compatibilidade cross-browser

Funcionalidades não funcionam consistentemente em todos os navegadores/dispositivos.

MÉDIO
Probabilidade: 30%
Impacto: Moderado
Mitigação: Testes rigorosos em Chrome, Firefox, Safari, Edge; polyfills para funcionalidades modernas; fallback para browsers antigos

R04 - Falha nas integrações de API externa

Google Maps, WhatsApp ou TrustIndex podem ter limitações ou mudanças de API.

BAIXO
Probabilidade: 20%
Impacto: Moderado
Mitigação: Verificar terms of service; planejar alternativas (mapas estáticos, links diretos); monitorar changelogs das APIs

R05 - Performance insatisfatória (Core Web Vitals)

Site não atinge métricas desejadas de carregamento e interatividade.

BAIXO
Probabilidade: 25%
Impacto: Moderado
Mitigação: Otimização de imagens (WebP, lazy loading); CDN para assets críticos; code splitting; minimização de CSS/JS

Legenda de Classificação:

ALTO: >70 probabilidade × impacto crítico
MÉDIO: 40-70 probabilidade × impacto moderado
MODERADO: Impacto menor, requer atenção
BAIXO: Baixa probabilidade e impacto
